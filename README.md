# AI-Workforce-Skills-Intelligence-Platform
End-to-end analytics project using Excel, Python, SQL, and Power BI to analyze AI job market trends, skill demand, salary intelligence, and future workforce forecasting.

## Project Overview
This project analyzes global AI hiring trends,
skill demand, salary patterns, workforce requirements
and future AI workforce outlook using Python, SQL and Power BI.

## Business Problem
Organizations need insights into:

- AI hiring trends
- Skill demand
- Compensation benchmarks
- Remote work adoption
- Future workforce requirements

  ## Tools & Technologies
- Excel
- Python
- SQL
- Power BI
- DAX

## Key Insights
- Healthcare and Automotive lead AI hiring.

- Hybrid work is the dominant work model.

- System Design is the highest-paying skill.

- USA offers the highest average salary.

- Government sector shows strongest demand growth.

- AI hiring accelerates significantly in early 2026.
